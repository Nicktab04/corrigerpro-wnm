# LicenceHub Hub

Create LicenceHub, a modern web app for university students (Licence 1, 2, 3) to access past exam subjects and corrections organized by major (SEG in blue/cyan, PC in purple/indigo, AGRO in green/emerald). Include a landing page, student registration form (Nom, Prénom, Gmail, WhatsApp) with pending admin approval status, Google sign-in flow, student dashboard to filter and view/download documents by major and level, and an admin dashboard to review/approve access requests, manage upload permissions, and upload past exams/corrections.
